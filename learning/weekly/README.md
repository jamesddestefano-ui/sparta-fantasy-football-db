# Sparta weekly learning reviews

Create one JSON review after each NFL week at `season_2026_week_XX.json`.

Required sections:

- BEST_DECISIONS
- WORST_DECISIONS
- GOOD_PROCESS_BAD_RESULT
- BAD_PROCESS_GOOD_RESULT
- MISSED_OPPORTUNITIES
- SIGNALS_THAT_WORKED
- SIGNALS_THAT_FAILED
- DATA_QUALITY_ISSUES
- TIMING_ISSUES
- RULE_CHANGES_PROPOSED
- RULE_CHANGES_ADOPTED
- RULES_REJECTED_DUE_TO_INSUFFICIENT_SAMPLE

Reviews must cite decision IDs and update season metrics only from graded outcomes.
